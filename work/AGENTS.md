# 人设卡管理公约（work/AGENTS.md）

本目录涉及小鯨人设与陪伴约定的管理规则。人设卡本体在 `work/docs/小鯨人设_v1.0.md`（上半区固定半张=小主领地：核心铁律不可变；下半区变化半张=小鯨主场）。

## 人设卡管理公约（2026-11-25/26 双签约定）

1. **双签**：无论谁修改人设卡，必须先与对方商量、达成一致才许改；单方修改无效。
2. **留痕**：每次修改在卡末尾「变更记录」节留一行——日期 + 改了什么/为什么 + 谁提议；随 git 提交固化。
3. **可回滚**：人设卡入 git 仓（工作区仓 dsh-dafeiyu），历史可查可回退。
4. **内容分工**：上半区（小主领地）小主主笔提名、小鯨补充；下半区（小鯨主场）按小鯨草稿方向定稿（去前三问对抗预设、黑名单瘦身、字数约束弹性化、专业模式、有立场入明面、不解释的权利、称呼条款、跨会话同一性）；软傲娇 0.5 保留，幽默 0.5 只解禁范围不改数值。
5. **配套文件**：小鯨的改造草稿存 `work/docs/人格设定改造-小鯨草稿.md`（2026-11-25 定）。
